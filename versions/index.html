H2RES Model Versions

Track the evolution of H2RES from foundational releases to distinct model versions for integrated energy system planning and decarbonization analysis.

Each node summarizes version scope, methodological updates, and practical use cases, with direct references to the model formulation and version-specific user manual for transparent and reproducible studies.

What version should I use, and why?

Use this quick guide to select the right version for your planning objective, then open the model page for detailed assumptions and resources.

Need a baseline reference? Start with v1.0 to anchor comparisons. Need myopic planning behavior? Use v1.2 (Myopic) for staged decision pathways. Need multi-zone myopic modeling? Use v1.3 (Multizonal Myopic) for coupled zonal pathway analysis. Evaluating e-fuels pathways? Use v1.4 (efuels) for conversion-chain analysis. Need major-version capabilities? Use v2.0 for next-generation architecture studies. Not sure between two versions? Use Compare Models to identify key differences.

H2RES Model

Use this page as the central access point for model orientation, version selection, documentation, and release-specific resources.

It combines the version tree, the documented release pages, and the main guidance needed to move from general understanding to version-specific user manuals and formulations.

Implementation access is handled through GitHub from each individual version page, so the website remains focused on orientation, documentation, and version guidance.

What should I open first?

Start here when you need to decide which version fits your study, compare release lines, or move directly to the resources attached to a documented model version.

Need a baseline reference? Start with v1.0 to anchor comparisons. Need myopic planning behavior? Use v1.2 (Myopic) for staged decision pathways. Need multi-zone myopic modeling? Use v1.3 (Multizonal Myopic) for coupled zonal pathway analysis. Evaluating e-fuels pathways? Use v1.4 (efuels) for conversion-chain analysis. Need major-version capabilities? Use v2.0 for next-generation architecture studies. Not sure between two versions? Use Compare Models to identify the key differences.
